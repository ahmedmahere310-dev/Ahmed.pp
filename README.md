# تطبيق HYDRA - تتبع السوائل والتغذية وتنبيهات الحمام الذكية 💧🚻

تطبيق أندرويد متطور مبني بأحدث تقنيات **Jetpack Compose** و **Material Design 3** و **Room Database**.

---

## 🚀 كيفية بناء وتحميل ملف الـ APK عبر GitHub Actions

تم تزويد هذا المستودع بملف **GitHub Actions Workflow** تلقائي وجاهز للعمل بمجرد رفع الكود إلى GitHub!

### الخطوات لتحميل ملف الـ APK:

1. **ارفع الكود إلى مستودع GitHub الخاص بك** (أو استخدم ميزة Push to GitHub في AI Studio).
2. افتح مستودعك على GitHub، واضغط على تبويب **`Actions`** من الشريط العلوي.
3. ستجد مهمة تعمل تلقائياً بعنوان **`Build & Export Android APK`**.
4. انتظر دقيقة أو دقيقتين حتى تكتمل المهمة بعلامة صح خضراء (✔).
5. اضغط على تشغيلة البناء المكتملة، وانزل لأسفل الصفحة لقسم **`Artifacts`**.
6. اضغط على **`Hydra-APK`** لتحميل الملف المضغوط الذي يحتوي على تطبيق `Hydra-v1.0.0.apk`.
7. انقل ملف الـ APK إلى هاتفك الأندرويد، وافتحه لتثبيته فوراً!

---

## ⚙️ تشغيل البناء يدوياً (Manual Trigger):
1. اذهب إلى تبويب **`Actions`**.
2. اختر من القائمة الجانبية: **`Build & Export Android APK`**.
3. اضغط على زر **`Run workflow`** من اليمين، ثم اضغط على الزر الأخضر للبدء فوراً.

---

## 📱 مميزات التطبيق الرئيسية:
- **تتبع ذكي للترطيب**: تسجيل كميات المياه والسوائل المختلفة مع حساب السعة الفسيولوجية.
- **تتبع الوجبات والسعرات**: تسجيل وجبات الإفطار والغداء والعشاء والسناك مع حساب السعرات الحرارية.
- **خوارزمية تنبؤ دخول الحمام**: حساب وقت الحاجة لدخول الحمام بدقة فسيولوجية بناءً على حجم السوائل المتناولة مع كمية السعرات ومواعيد الزيارات السابقة.
- **تنبيهات وإشعارات ذكية**: إشعارات تفاعلية تذكرك بموعد الحمام وشرب الماء مع إمكانية التأجيل (Snooze) أو التسجيل بنقرة واحدة من شريط الإشعارات.
- **حفظ محلي كامل (Offline-First)**: جميع البيانات محفوظة داخل قاعدة بيانات Room على جهازك بأمان تام وسرعة فائقة.
